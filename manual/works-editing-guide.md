## 1. 全体構成

### 編集で触るファイル

| ファイル               | 役割                                                           | 編集頻度 |
| ---------------------- | -------------------------------------------------------------- | -------- |
| `src/data/works.json`  | 作品データ（タイトル・画像パス・説明文・カテゴリ・レイアウト） | 高       |
| `public/images/works/` | 画像ファイルの格納先                                           | 高       |

### 触らないファイル（コンポーネント）

| ファイル                            | 役割                                                  |
| ----------------------------------- | ----------------------------------------------------- |
| `src/pages/works.astro`             | ページテンプレート（ヒーロー画像 + Gallery 呼び出し） |
| `src/components/Gallery.astro`      | カテゴリナビ + グリッド表示                           |
| `src/components/GalleryItem.astro`  | 個別作品カード                                        |
| `src/components/GalleryModal.astro` | 拡大表示ダイアログ                                    |
| `public/scripts/gallery.js`         | フィルタ・モーダル・フォールバック処理                |

通常の作品追加・編集では **`works.json` と画像ファイルのみ** を編集します。

## 2. 作品の追加・編集

### 2.1 データファイルの場所

```
src/data/works.json
```

### 2.2 作品データの構造

```jsonc
{
  "title": "西芳寺（苔寺） 三重納経塔",
  "src": "img/001_tou_001saihouji-l.jpg",
  "thumbnail": "img/001_tou_001saihouji-s.jpg",
  "text": "西芳寺（苔寺） 三重納経塔 新築 京都市 昭和53年 （財）建築研究協会",
  "category": "tower",
  "layout": "grid-3",
}
```

| フィールド  | 型     | 説明                                                 |
| ----------- | ------ | ---------------------------------------------------- |
| `title`     | string | 作品名（建物名）                                     |
| `src`       | string | フルサイズ画像のパス（`img/` プレフィックス付き）    |
| `thumbnail` | string | サムネイル画像のパス（`img/` プレフィックス付き）    |
| `text`      | string | 説明文（名称＋工事種別＋所在地＋年代＋設計者）       |
| `category`  | string | カテゴリ ID（後述）                                  |
| `layout`    | string | 表示レイアウト：`"single"` / `"grid-2"` / `"grid-3"` |

### 2.3 作品を追加する

`items` 配列の **該当カテゴリの末尾** に新しいオブジェクトを追加します。

```json
{
  "title": "○○寺 本堂",
  "src": "img/002_garan_099example-l.jpg",
  "thumbnail": "img/002_garan_099example-s.jpg",
  "text": "○○寺 本堂 新築 京都市 令和7年",
  "category": "temple",
  "layout": "grid-3"
}
```

**注意点：**

- 同じカテゴリの作品はまとめて配置してください（カテゴリごとにセクション表示されるため）
- 同じレイアウトの作品が連続すると、自動的にグリッドにグループ化されます
- JSON の末尾カンマに注意（最後の要素の後にカンマを付けない）

### 2.4 作品を編集する

該当する作品オブジェクトのフィールドを直接編集します。

### 2.5 作品を削除する

該当する作品オブジェクトを `items` 配列から削除します。画像ファイルも不要であれば `public/images/works/` から削除します。

## 3. 画像の準備

### 3.1 命名規則

```
{カテゴリ番号}_{カテゴリ略称}_{連番}{建物名ローマ字}-{サイズ}.jpg
```

#### カテゴリ番号と略称

| 番号  | 略称       | カテゴリ            |
| ----- | ---------- | ------------------- |
| `001` | `tou`      | 塔 (Tower)          |
| `002` | `garan`    | 伽藍 (Temple)       |
| `003` | `jinja`    | 神社 (Shrine)       |
| `004` | `mon`      | 門 (Gate)           |
| `005` | `shourou`  | 鐘楼 (Bell Tower)   |
| `006` | `shuzouko` | 収蔵庫 (Repository) |
| `007` | `christ`   | 教会 (Church)       |

#### サイズサフィックス

| サフィックス | 用途                                                   | 目安サイズ     |
| ------------ | ------------------------------------------------------ | -------------- |
| `-l.jpg`     | フルサイズ（モーダル表示 / single・grid-2 レイアウト） | 幅 1000px 程度 |
| `-s.jpg`     | サムネイル（grid-3 レイアウト）                        | 幅 300px 程度  |

#### 例

```
001_tou_001saihouji-l.jpg   ← フルサイズ
001_tou_001saihouji-s.jpg   ← サムネイル
```

### 3.2 画像の配置先

```
public/images/works/
```

**必ず `-l.jpg`（フルサイズ）と `-s.jpg`（サムネイル）のペアで用意してください。**

### 3.3 works.json でのパス指定

画像パスには `img/` プレフィックスを付けます。コンポーネント内部で `/images/works/` に変換されます。

```
実ファイル: public/images/works/001_tou_001saihouji-l.jpg
JSON の src: "img/001_tou_001saihouji-l.jpg"
```

**パス変換の仕組み：**

| JSON の値                       | 表示時のパス                              |
| ------------------------------- | ----------------------------------------- |
| `img/001_tou_001saihouji-l.jpg` | `/images/works/001_tou_001saihouji-l.jpg` |
| `img/001_tou_001saihouji-s.jpg` | `/images/works/001_tou_001saihouji-s.jpg` |

`GalleryItem.astro` が `img/` を除去し `/images/works/` を付与しています。

## 4. カテゴリの管理

### 4.1 既存カテゴリ

```json
"categories": [
  { "id": "tower",      "label": "塔",     "labelEn": "Tower" },
  { "id": "temple",     "label": "伽藍",   "labelEn": "Temple" },
  { "id": "shrine",     "label": "神社",   "labelEn": "Shrine" },
  { "id": "gate",       "label": "門",     "labelEn": "Gate" },
  { "id": "belltower",  "label": "鐘楼",   "labelEn": "Bell Tower" },
  { "id": "repository", "label": "収蔵庫", "labelEn": "Repository" },
  { "id": "church",     "label": "教会",   "labelEn": "Church" }
]
```

### 4.2 カテゴリを追加する

1. `categories` 配列に新しいオブジェクトを追加

```json
{ "id": "bridge", "label": "橋", "labelEn": "Bridge" }
```

2. 画像ファイルの命名用に番号と略称を決める（例：`008_hashi`）
3. 作品データの `category` に新しい ID を使用

**カテゴリナビのサムネイルは自動生成されます**（該当カテゴリの最初の作品の画像が使われます）。

### 4.3 表示順

カテゴリの表示順は `categories` 配列の並び順で決まります。サイドバーのカテゴリボタンもこの順で表示されます。

## 5. レイアウトの種類

### 5.1 3種類のレイアウト

| layout 値  | グリッド    | 表示画像              | 用途                   |
| ---------- | ----------- | --------------------- | ---------------------- |
| `"grid-3"` | 3列         | サムネイル (`-s.jpg`) | 標準的な作品一覧       |
| `"grid-2"` | 2列         | フルサイズ (`-l.jpg`) | やや大きく見せたい作品 |
| `"single"` | 1列（全幅） | フルサイズ (`-l.jpg`) | 特に目立たせたい作品   |

### 5.2 グループ化の仕組み

同じレイアウトが連続する作品は自動的にグリッドにまとめられます。

```
作品A (grid-3) ─┐
作品B (grid-3)  ├→ 3列グリッド
作品C (grid-3) ─┘
作品D (single) ───→ 全幅表示
作品E (grid-2) ─┐
作品F (grid-2) ─┘→ 2列グリッド
```

**レイアウトの切り替わりは `items` 配列の並び順で決まります。** 意図したグリッドになるよう、同じレイアウトの作品は連続して配置してください。

### 5.3 レイアウト選択の目安

- 標準的な作品 → `grid-3`
- 横長や写真が特徴的な作品 → `grid-2`
- 代表作や大型案件 → `single`

## 6. テキストの書き方

### 6.1 title フィールド

建物名を記載します。

```
"title": "西芳寺（苔寺） 三重納経塔"
```

### 6.2 text フィールド

以下の情報を半角スペース区切りで記載します。

```
{建物名} {工事種別} {所在地} {年代} {設計者（任意）}
```

例：

```
"text": "西芳寺（苔寺） 三重納経塔 新築 京都市 昭和53年 （財）建築研究協会"
"text": "総本山善通寺 五重塔 半解体修理 善通寺市 平成5年"
```

**表示の仕組み：**

コンポーネントは `text` を `title` 部分とそれ以降に分割して表示します。

- 1行目（太字）：`title` と一致する部分
- 2行目（小さい文字）：`title` 以降のテキスト（工事種別・所在地・年代等）

そのため、**`text` は `title` の文字列で始まるようにしてください。**

```
title: "西芳寺（苔寺） 三重納経塔"
text:  "西芳寺（苔寺） 三重納経塔 新築 京都市 昭和53年 ..."
       ^^^^^^^^^^^^^^^^^^^^^^^^^ ← title と一致
                                  ^^^^^^^^^^^^^^^^^^^^^^^^ ← 2行目に表示
```

### 6.3 title の先頭 `>` について

一部の作品タイトルに `>` や `>>` プレフィックスが付いています。

```
"title": ">本願寺（西本願寺）阿弥陀堂"
"title": ">>日龍峯寺 多宝塔"
```

これはコンポーネントの `normalize` 関数で除去されるため表示には影響しませんが、新規追加時には付けない方が望ましいです。

## 8. トラブルシューティング

### 画像が表示されない

1. **ファイル名を確認** — `works.json` のパスと `public/images/works/` のファイル名が一致しているか
2. **`img/` プレフィックス** — JSON では `"img/filename.jpg"` の形式になっているか
3. **ファイルの存在** — `-l.jpg` と `-s.jpg` の両方が存在するか

### カテゴリが表示されない

1. **`category` の値** — `categories` 配列の `id` と一致しているか（大文字小文字に注意）
2. **作品が存在するか** — そのカテゴリに1件以上の作品があるか

### レイアウトが崩れる

1. **`layout` の値** — `"single"` / `"grid-2"` / `"grid-3"` のいずれかか（スペルミス注意）
2. **並び順** — 同じレイアウトの作品が連続しているか

### JSON パースエラー

1. **末尾カンマ** — 配列の最後の要素の後にカンマがないか
2. **引用符** — すべての文字列がダブルクォートで囲まれているか
3. **エスケープ** — テキスト内にダブルクォートがあれば `\"` でエスケープする

### CSP エラーがコンソールに出る

開発サーバーでは Astro dev toolbar のインラインスクリプトに対する CSP エラーが表示される場合がありますが、`middleware.js` で dev 環境のみ `unsafe-inline` を許可しているため動作に影響はありません。本番ビルドでは `public/_headers` のポリシーが適用されます。

## 9. 開発者向け実装ルール

### 9.1 背景画像の設定方法

**外部 URL（microCMS などの変数展開）を `style` 属性に直接埋め込んではいけません。**

本番 CSP では `style-src 'unsafe-inline'` を許可していないため、`style=""` に変数を展開すると背景画像がブロックされます。

#### NG パターン

```astro
<!-- style 属性に直接展開 → CSP でブロックされる -->
<div style={`background-image: url(${imageUrl});`}></div>
```

#### OK パターン（`data-bg-url` + JS）

```astro
<!-- data 属性でURLを渡す -->
<div class="my-image js-bg-image" data-bg-url={imageUrl}></div>
```

```typescript
// Astro の <script> ブロックで JS DOM プロパティ経由でセット
// element.style.backgroundImage の代入は CSP style-src の対象外
document.querySelectorAll<HTMLElement>(".js-bg-image").forEach((el) => {
  const url = el.dataset.bgUrl;
  if (url) el.style.backgroundImage = `url(${url})`;
});
```

**なぜ安全か：** HTML の `style=""` 属性（インラインスタイル）は CSP `style-src-attr` で制御されますが、JS の `element.style.backgroundImage = ...` は DOM プロパティへの代入であり CSP の適用外です。

#### 静的な背景色・CSS クラスで完結する場合

CSS でハードコードする背景画像やクラスベースのスタイルは制限の対象外です。

```css
/* OK: 外部 CSS ファイル内は style-src-elem の対象 → 'self' で許可済み */
.hero__image {
  background-image: url("/images/hero.webp");
}
```
