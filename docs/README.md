# Astro-Site プロジェクト概要

microCMS と連携した Astro ベースのウェブサイトプロジェクトです。

## 技術スタック

| カテゴリ       | 技術                    |
| -------------- | ----------------------- |
| フレームワーク | Astro 5.x (SSG モード)  |
| ホスティング   | Cloudflare Pages        |
| CMS            | microCMS                |
| バリデーション | Zod                     |
| 言語           | TypeScript / JavaScript |

## 主な機能

- **トップページ** - microCMS からヒーロー画像・テキストを取得
- **FAQ** - アコーディオン形式のよくある質問セクション
- **ニュース** - 記事一覧・詳細ページ (動的ルーティング)
- **お問い合わせ** - フォームバリデーション付きコンタクトフォーム
- **セキュリティ** - ミドルウェアでセキュリティヘッダー自動設定

## クイックスタート

```bash
# 依存関係インストール
npm install

# 開発サーバー起動 (http://localhost:4321)
npm run dev

# 本番ビルド
npm run build
```
